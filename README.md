# Quick Actions QoL

A Star Empire mod. Makes the Quick Actions hotbar draggable and adds a
toggleable fighter auto-launch while in combat -- about as fast as an
attentive player mashing the key, not superhuman.

![Quick Actions bar screenshot](.github/images/quickActionsBarScreenshot.png)

## Install

Grab the latest `.semod` from [Releases](../../releases/latest) and drop
it into the Star Empire Mod Manager.
